# My Universe — version 0.1

Première base de l'application personnelle My Universe.

## Contenu
- Accueil et navigation
- Création d'univers
- Cartes collector (catégories et rareté)
- Notes et idées
- Liste de tâches
- Bibliothèque de titres musicaux (sans streaming)
- Compagnon personnalisable parmi 11 choix
- Sauvegarde locale dans le navigateur
- Export JSON des données
- Base PWA avec cache hors connexion

## Important
Cette version stocke les données sur l'appareil utilisé. La synchronisation entre iPhone et PC, les comptes personnels, les notifications et un assistant vocal intelligent ne sont pas encore intégrés. Ils seront développés après validation de cette première base.

Les données personnelles ne doivent pas être ajoutées au dépôt GitHub public.
